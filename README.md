# 🎬 Netflix Content Analysis Dashboard

A professional data analytics project exploring global streaming trends, content catalogs, and distribution metrics using the Netflix titles dataset.

![Netflix Content Analysis Dashboard](dashboard_screenshot.png)

## 📊 Overview

This project dives deep into the Netflix catalog to uncover patterns in global content production, audience maturity ratings, and release trends. Designed as an interactive dashboard, it transforms raw data into actionable media intelligence.

---

## 🔍 Key Dashboard Metrics (Media Overview)

* **Type:** Categorization between Movies and TV Shows.
* **Country:** Primary and secondary production hubs worldwide.
* **Rating:** Age-appropriate audience segments (e.g., TV-MA, PG-13, TV-PG).
* **Release Year:** Historical timeline of original content release dates.
* **Duration:** Movie runtimes (in minutes) and TV show longevity (in seasons).

---

## 🚀 Key Features & Highlights

* **Catalog Breakdown:** Clear visualization of the ratio between cinematic releases and episodic television.
* **Geographical Reach:** Mapping content contributions from major entertainment markets like the US, India, UK, and South Korea.
* **Audience Targeting:** Analysis of maturity ratings to understand demographic focus.
* **Growth Timeline:** Tracking the exponential expansion of streaming libraries over recent decades.
